
# HRS: A Web-based Audio Manipulator

Web app made for adjusting the speed of an uploaded audio file.

- Aimed to generate a unique solution for artists looking to showcase their music on social media. 
- Also functions as an audio player with traversable waveform.
- Use it to generate inspiration by hearing your sounds at a different speed and pitch.


## Features

- Custom File Input element widget
- Traversable waveform
- Pitch fader to adjust speed + pitch
- Bypass button for A/B testing
- Sleek neumorphic UI
- Responsive (mobile + tablet support)
